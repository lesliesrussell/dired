# UI Styles (rich / clean / minimal) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make dired's UI configurable between three looks (`rich`, `clean`, `minimal`) with per-feature overrides, using only ratatui.

**Architecture:** A pure resolver in `dired-config` turns `[display] style` + `[display.ui]` overrides into a `UiOptions` struct. `dired-tui::render::draw` resolves it each frame from `app.config.display` (so `draw`'s signature does not change) and threads it through a `DrawCx`. Pure, unit-testable pieces (size/age colors, scrollbar, popup, mode line, icons) live in a new `dired-tui/src/widgets.rs`. The app is told how many rows the chrome (borders, directory header) consumes so scroll math stays correct.

**Tech Stack:** Rust 2021, ratatui 0.30 (`Block`, `Scrollbar`, `Clear`, `TestBackend`), crossterm 0.29 (unchanged), serde/toml config.

**Spec:** `docs/superpowers/specs/2026-10-12-ui-styles-design.md` (bead `dired-p2d`, branch `dired-p2d`). Task 2 amends the spec where this plan deviates (see "Amendments").

## Global Constraints

- Only ratatui/crossterm already in the workspace; **no new dependencies**.
- `render::draw(f: &mut Frame, app: &mut App, theme: &Theme)` signature is **unchanged** (existing tests call it).
- No change to the event loop in `crates/dired-tui/src/lib.rs`, to key handling, or to `render::sanitize` / `render::truncate` semantics. Every filename/path/candidate shown must still go through `truncate` (which sanitizes).
- Default style is `clean`; presets: `rich`, `clean`, `minimal` (order of `cycle-style`: rich, clean, minimal).
- Preset table (exact):

  | feature       | rich      | clean     | minimal |
  |---------------|-----------|-----------|---------|
  | borders       | true      | false     | false   |
  | icons         | true      | false     | false   |
  | scrollbar     | true      | true      | true    |
  | column_colors | true      | true      | true    |
  | mode_line     | segmented | segmented | plain   |
  | popup         | true      | true      | true    |

  `clean` also sets `header_rule` and `roomy` (fixed preset properties, not options).
- Config errors are nonfatal: they go to *Diagnostics* as `Diagnostic::error`, and the value falls back to the default (`clean`, no override).
- Nerd Font glyph defaults are written as `\u{...}` escapes in source (never raw private-use characters).
- Every new block of code carries a comment `// dired-p2d` (bead ID only), one per contiguous block.
- Quality gates after every task: `cargo test --workspace --locked` and `cargo clippy --workspace --all-targets --locked -- -D warnings` pass.

```rust
// dired-p2d
//! UI style presets and per-feature overrides, resolved to concrete options.

use serde::{Deserialize, Serialize};

use crate::DisplayConfig;

/// Built-in style names, in `cycle-style` order.
pub const STYLES: &[&str] = &["rich", "clean", "minimal"];

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum UiStyle {
    Rich,
    Clean,
    Minimal,
}

impl UiStyle {
    pub fn parse(s: &str) -> Option<UiStyle> {
        match s {
            "rich" => Some(UiStyle::Rich),
            "clean" => Some(UiStyle::Clean),
            "minimal" => Some(UiStyle::Minimal),
            _ => None,
        }
    }

    pub fn name(self) -> &'static str {
        match self {
            UiStyle::Rich => "rich",
            UiStyle::Clean => "clean",
            UiStyle::Minimal => "minimal",
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ModeLine {
    Segmented,
    Plain,
}

impl ModeLine {
    pub fn parse(s: &str) -> Option<ModeLine> {
        match s {
            "segmented" => Some(ModeLine::Segmented),
            "plain" => Some(ModeLine::Plain),
            _ => None,
        }
    }
}

/// `[display.ui]`: every key optional; set keys override the preset.
#[derive(Debug, Clone, PartialEq, Eq, Default, Serialize, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct UiOverrides {
    pub borders: Option<bool>,
    pub icons: Option<bool>,
    pub scrollbar: Option<bool>,
    pub column_colors: Option<bool>,
    /// `segmented` or `plain`.
    pub mode_line: Option<String>,
    pub popup: Option<bool>,
}

impl UiOverrides {
    pub fn is_empty(&self) -> bool {
        *self == UiOverrides::default()
    }
}

/// Concrete UI options after applying the preset and overrides.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct UiOptions {
    pub style: UiStyle,
    pub borders: bool,
    pub icons: bool,
    pub scrollbar: bool,
    pub column_colors: bool,
    pub mode_line: ModeLine,
    pub popup: bool,
    /// `clean`: a `─` rule under the directory header.
    pub header_rule: bool,
    /// `clean`: left gutter and wider gaps between columns.
    pub roomy: bool,
}

impl UiOptions {
    pub fn resolve(d: &DisplayConfig) -> UiOptions {
        let style = UiStyle::parse(&d.style).unwrap_or(UiStyle::Clean);
        let rich = style == UiStyle::Rich;
        let o = &d.ui;
        let default_mode = if style == UiStyle::Minimal { ModeLine::Plain } else { ModeLine::Segmented };
        UiOptions {
            style,
            borders: o.borders.unwrap_or(rich),
            icons: o.icons.unwrap_or(rich),
            scrollbar: o.scrollbar.unwrap_or(true),
            column_colors: o.column_colors.unwrap_or(true),
            mode_line: o.mode_line.as_deref().and_then(ModeLine::parse).unwrap_or(default_mode),
            popup: o.popup.unwrap_or(true),
            header_rule: style == UiStyle::Clean,
            roomy: style == UiStyle::Clean,
        }
    }

    /// Rows a directory buffer's header takes (path or column labels, plus the rule).
    pub fn dir_header_rows(&self) -> u16 {
        if self.header_rule {
            2
        } else {
            1
        }
    }

    /// Rows each window's frame takes beyond its mode line.
    pub fn border_rows(&self) -> u16 {
        if self.borders {
            2
        } else {
            0
        }
    }
}
```

```rust
fn validate_display(d: &mut DisplayConfig, source: &str, diags: &mut Vec<Diagnostic>) {
    if UiStyle::parse(&d.style).is_none() {
        diags.push(Diagnostic::error(
            source,
            format!("display.style `{}` is not one of {}", d.style, STYLES.join(", ")),

            diags.push(Diagnostic::error(
                source,
                format!("display.ui.mode_line `{m}` must be `segmented` or `plain`"),
            ));
            d.ui.mode_line = None;
        }
    }
}
```

```markdown
## Amendments (from implementation planning)

- **Chrome plumbing.** `dired-app` computes each window's scroll window
  itself (`viewport`, `adjust_top`, `render_view`) and assumed exactly one
  directory header row and no borders. The renderer therefore calls the new
  `App::set_chrome(border_rows, dir_header_rows)` every frame before
  `set_window_area`; `viewport = window_height - 1 - border_rows` and
  directory scrolling subtracts `dir_header_rows`. (Replaces the earlier
  statement that "the inner rect is what `set_window_area` receives".)
```

```rust
pub fn size_style(theme: &Theme, size: u64) -> Style {

/// Modification-time color by age: < 1 day success, < 30 days normal,
/// < 1 year dim, older dim italic. Unknown times are dim.
pub fn age_style(theme: &Theme, modified: Option<SystemTime>, now: SystemTime) -> Style {

        a if a < 30 * DAY => theme.normal,
        a if a < 365 * DAY => theme.dim,
        _ => theme.dim.add_modifier(Modifier::ITALIC),
```

```rust
/// Draw one window: body, scrollbar and mode line. Returns the cursor
/// position when this is the selected window and a Wdired edit is active.
#[allow(clippy::too_many_arguments)]
fn draw_window(
    f: &mut Frame,
    app: &mut App,
    cx: &DrawCx,
    wid: dired_app::windows::WindowId,
    r: dired_app::windows::Rect,
    selected: bool,
    hint: &Option<String>,
    warea: Rect,
) -> Option<Position> {
    let theme = cx.theme;
    let rect = Rect::new(warea.x + r.x, warea.y + r.y, r.w, r.h);
    if rect.width == 0 || rect.height == 0 {
        return None;
    }
    if r.x > 0 {
        let rule: Vec<Line> = (0..rect.height).map(|_| Line::from(Span::styled("│", theme.dim))).collect();
        f.render_widget(Paragraph::new(rule), Rect::new(rect.x - 1, rect.y, 1, rect.height));
    }
    let body = Rect::new(rect.x, rect.y, rect.width, rect.height.saturating_sub(1));
    let mode = Rect::new(rect.x, rect.y + rect.height.saturating_sub(1), rect.width, 1);
    let buf = app.window(wid).map(|w| w.buffer)?;
    let view = app.render_view(wid, body.height as usize);
    let status = app.status_for(buf);

    // Content extent: (total rows, rows visible), reusing the preview lines.
    let dir_hdr = cx.ui.dir_header_rows();
    let mut preview: Option<(Vec<dired_app::buffers::TextLine>, usize)> = None;
    let mut hdr_rows = 0;
    let (total, shown) = match app.buffer_mut(buf).map(|b| &mut b.kind) {
        Some(BufferKind::Dir(d)) => {
            d.ensure_view();
            hdr_rows = dir_hdr;
            (d.rows().len(), (body.height as usize).saturating_sub(dir_hdr as usize))
        }
        Some(BufferKind::Text(t)) => (t.lines.len(), body.height as usize),
        Some(BufferKind::Preview(p)) => {
            let (lines, first) = p.lines();
            let n = lines.len();
            preview = Some((lines, first));
            (n, body.height as usize)
        }
        None => (0, 0),
    };
    let show_sb = cx.ui.scrollbar && total > shown && body.width > 8 && shown > 0;
    let (body, sb) = if show_sb {
        let sb = Rect::new(
            body.x + body.width - 1,
            body.y + hdr_rows,
            1,
            body.height.saturating_sub(hdr_rows),
        );
        (Rect::new(body.x, body.y, body.width - 1, body.height), Some(sb))
    } else {
        (body, None)
    };

    let mut cursor = None;
    match app.buffer_mut(buf).map(|b| &mut b.kind) {
        Some(BufferKind::Dir(d)) => {

            if selected {
                cursor = c;
            }

        Some(BufferKind::Text(t)) => draw_lines(f, body, &t.lines, view.top, Some(view.point), theme, selected),
```

```rust
pub fn popup_window(selected: usize, view_rows: usize) -> usize {
    selected.saturating_sub(view_rows.saturating_sub(1))

/// Rectangle for the popup box: as wide as the longest candidate plus
/// borders and padding, as tall as the shown candidates plus borders, its
/// bottom edge just above `anchor`. Height 0 when there is no room.
pub fn popup_rect(screen: Rect, anchor: Rect, candidates: &[String], max_rows: usize) -> Rect {
    let rows = candidates.len().min(max_rows) as u16;
    let longest = candidates.iter().map(|c| c.width()).max().unwrap_or(0);
    let w = (longest as u16).saturating_add(4).min(screen.width);
    let room = anchor.y.saturating_sub(screen.y);
    let h = (rows + 2).min(room);
    Rect::new(screen.x, anchor.y - h, w, h)
}

/// Draw the candidates in a rounded box floating above `anchor`.
pub fn draw_popup(f: &mut Frame, screen: Rect, anchor: Rect, candidates: &[String], selected: usize, max_rows: usize, theme: &Theme) {
    let r = popup_rect(screen, anchor, candidates, max_rows);
    if r.height < 3 || r.width < 5 {
        return;
    }
    f.render_widget(Clear, r);
    let block = Block::bordered().border_type(BorderType::Rounded).border_style(theme.dim);
    let inner = block.inner(r);
    f.render_widget(block, r);
    let view_rows = inner.height as usize;
    let start = popup_window(selected, view_rows);
    let text_w = inner.width.saturating_sub(2) as usize;
    let lines: Vec<Line> = candidates
        .iter()
        .enumerate()
        .skip(start)
        .take(view_rows)
        .map(|(i, c)| {
            let st = if i == selected { theme.point } else { theme.normal };
            let t = truncate(c, text_w);
            let pad = text_w.saturating_sub(t.width());
            Line::from(Span::styled(format!(" {t}{} ", " ".repeat(pad)), st))
        })
        .collect();
    f.render_widget(Paragraph::new(lines), inner);
}
```

```rust
/// Pad `s` with spaces to `width` display columns (no truncation).
fn pad_to(s: &str, width: usize) -> String {
    let w = s.width();
    if w >= width {
        s.to_string()
    } else {
        format!("{s}{}", " ".repeat(width - w))
    }
}

/// Two-tone mode line built from the status text: the buffer name on the
/// left, then the remaining segments (status split on double spaces),
/// `n/total`, and the prefix-key hint. Always exactly `width` columns wide.
/// `powerline` additionally needs two distinct backgrounds in the theme.
pub fn segmented_mode_line(
    theme: &Theme,
    status: &str,
    pos: Option<(usize, usize)>,
    hint: Option<&str>,
    width: usize,
    selected: bool,
    powerline: bool,
) -> Line<'static> {
    let mut segs = status.split("  ").filter(|s| !s.is_empty());
    let name = segs.next().unwrap_or("").to_string();
    let mut rest: Vec<String> = segs.map(str::to_string).collect();
    if let Some((n, t)) = pos {
        rest.push(format!("{n}/{t}"));
    }
    if selected {
        if let Some(h) = hint {
            rest.push(h.to_string());
        }
    }
    let alt_bg = theme.inactive.bg.or(theme.point.bg);
    let head_style = if selected { theme.status.add_modifier(Modifier::BOLD) } else { theme.inactive };
    let tail_style = if !selected {
        theme.inactive
    } else if let Some(bg) = alt_bg {
        Style { bg: Some(bg), ..theme.status }.remove_modifier(Modifier::REVERSED)
    } else {
        theme.status
    };
    let use_powerline = powerline
        && selected
        && matches!((theme.status.bg, alt_bg), (Some(a), Some(b)) if a != b);

    let head = truncate(&format!(" {name} "), width);
    let head_w = head.width();
    let sep: Option<Span<'static>> = if use_powerline {
        Some(Span::styled("\u{e0b0}", Style::default().fg(theme.status.bg.unwrap()).bg(alt_bg.unwrap())))
    } else if head_w < width {
        Some(Span::styled("│", tail_style))
    } else {
        None
    };
    let sep_w = sep.as_ref().map(|s| s.content.width()).unwrap_or(0);
    let room = width.saturating_sub(head_w + sep_w);
    let tail = pad_to(&truncate(&format!(" {} ", rest.join(" │ ")), room), room);

    let mut spans = vec![Span::styled(head, head_style)];
    if room > 0 || use_powerline {
        spans.extend(sep);
    }
    if room > 0 {
        spans.push(Span::styled(tail, tail_style));
    }
    let line = Line::from(spans);
    // A separator that does not fit would overflow; trim by rebuilding as plain text.
    if line.width() > width {
        return Line::from(Span::styled(pad_to(&truncate(&format!(" {name} "), width), width), head_style));
    }
    line
}
```

```rust
// dired-p2d
/// Draw one window: frame, body, scrollbar and mode line. Returns the cursor
/// position when this is the selected window and a Wdired edit is active.
#[allow(clippy::too_many_arguments)]
fn draw_window(
    f: &mut Frame,
    app: &mut App,
    cx: &DrawCx,
    wid: dired_app::windows::WindowId,
    r: dired_app::windows::Rect,
    selected: bool,
    hint: &Option<String>,
    warea: Rect,
) -> Option<Position> {
    let theme = cx.theme;
    let rect = Rect::new(warea.x + r.x, warea.y + r.y, r.w, r.h);
    if rect.width == 0 || rect.height == 0 {
        return None;
    }
    // Side-by-side windows are separated by a rule, unless frames do it.
    if r.x > 0 && !cx.ui.borders {
        let rule: Vec<Line> = (0..rect.height).map(|_| Line::from(Span::styled("│", theme.dim))).collect();
        f.render_widget(Paragraph::new(rule), Rect::new(rect.x - 1, rect.y, 1, rect.height));
    }
    let outer = Rect::new(rect.x, rect.y, rect.width, rect.height.saturating_sub(1));
    let mode = Rect::new(rect.x, rect.y + rect.height.saturating_sub(1), rect.width, 1);
    let body = if cx.ui.borders { Block::bordered().inner(outer) } else { outer };
    let buf = app.window(wid).map(|w| w.buffer)?;
    let view = app.render_view(wid, body.height as usize);
    let status = app.status_for(buf);
    let name = app.buffer(buf).map(|b| b.name.clone()).unwrap_or_default();

    // Content extent: (total rows, rows visible), the border title, and the
    // preview lines (computed once and reused for drawing).
    let dir_hdr = cx.ui.dir_header_rows();
    let mut preview: Option<(Vec<dired_app::buffers::TextLine>, usize)> = None;
    let mut hdr_rows = 0;
    let mut has_pos = true;
    let mut title = format!(" {name} ");
    let (total, shown) = match app.buffer_mut(buf).map(|b| &mut b.kind) {
        Some(BufferKind::Dir(d)) => {
            d.ensure_view();
            hdr_rows = dir_hdr;
            let scan = d.scan_summary();
            let state = if scan != "done" { format!("  [{scan}]") } else { String::new() };
            title = format!(" {}{state} ", d.root.display());
            (d.rows().len(), (body.height as usize).saturating_sub(dir_hdr as usize))
        }
        Some(BufferKind::Text(t)) => (t.lines.len(), body.height as usize),
        Some(BufferKind::Preview(p)) => {
            has_pos = false;
            let (lines, first) = p.lines();
            let n = lines.len();
            preview = Some((lines, first));
            (n, body.height as usize)
        }
        None => (0, 0),
    };

    // Frame first, so the content and scrollbar draw over it.
    if cx.ui.borders && outer.width >= 2 && outer.height >= 2 {
        let accent = if selected { theme.header } else { theme.dim };
        let title = truncate(&title, (outer.width as usize).saturating_sub(4));
        let block = Block::bordered()
            .border_type(BorderType::Rounded)
            .border_style(accent)
            .title(Line::from(Span::styled(title, accent)));
        f.render_widget(block, outer);
    }

    // Scrollbar: on the right border when framed, else in a reserved column.
    let show_sb = cx.ui.scrollbar && total > shown && body.width > 8 && shown > 0;
    let (body, sb) = if show_sb && cx.ui.borders {
        let top = outer.y + 1 + hdr_rows;
        let h = outer.height.saturating_sub(2 + hdr_rows);
        (body, Some(Rect::new(outer.x + outer.width - 1, top, 1, h)))
    } else if show_sb {
        let sb = Rect::new(body.x + body.width - 1, body.y + hdr_rows, 1, body.height.saturating_sub(hdr_rows));
        (Rect::new(body.x, body.y, body.width - 1, body.height), Some(sb))
    } else {
        (body, None)
    };

    let mut cursor = None;
    if body.width > 0 && body.height > 0 {
        match app.buffer_mut(buf).map(|b| &mut b.kind) {
            Some(BufferKind::Dir(d)) => {
                let c = draw_dir(f, body, d, cx, view.point, view.top, selected);
                if selected {
                    cursor = c;
                }
            }
            Some(BufferKind::Text(t)) => draw_lines(f, body, &t.lines, view.top, Some(view.point), theme, selected),
            Some(BufferKind::Preview(_)) => {
                if let Some((lines, first)) = &preview {
                    draw_lines(f, body, lines, view.top, Some(first + view.point), theme, selected);
                }
            }
            None => {}
        }
    }
    if let Some(sb) = sb {
        widgets::draw_scrollbar(f, sb, total, view.top, shown, theme);
    }

    // Mode line (the prefix-key hint shows in the selected window's).
    let w = mode.width as usize;
    match cx.ui.mode_line {
        dired_config::ModeLine::Segmented => {
            let pos = if total == 0 || !has_pos { None } else { Some((view.point + 1, total)) };
            let line =
                widgets::segmented_mode_line(theme, &status, pos, hint.as_deref(), w, selected, cx.ui.icons);
            f.render_widget(Paragraph::new(line), mode);
        }
        dired_config::ModeLine::Plain => {
            let text = match (hint, selected) {
                (Some(h), true) => format!(" {}  │ {}", truncate(&status, w / 2), h),
                _ => format!(" {status}"),
            };
            let style = if selected { theme.status } else { theme.inactive };
            f.render_widget(Paragraph::new(pad_right(&truncate(&text, w), w)).style(style), mode);
        }
    }
    cursor
}
```
